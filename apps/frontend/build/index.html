Sound profiles

Each profile has its own sound, volume, and duration. Starting a profile replaces the current playback.

    New profile

    A duration of 0 plays until stopped or replaced. With repeat off, the sound plays once.

    Renaming preserves linked actions. Changes take effect the next time the profile starts.

    Audio output

    In Docker, pass /dev/snd into the container. Use “default” for the VM’s default sound output.

    This controls the VM’s sound output. A volume above zero unmutes it.

    Use Audio with the alarm

    Pair this bridge with the alarm controller. Use Play a profile during the exit delay, entry delay, or alarm. Use Stop playback when disarming and rearming.
